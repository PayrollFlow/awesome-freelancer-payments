# Contributing

Thanks for helping improve **Awesome Freelancer Payments**!

## How to add an entry

1. Fork this repository and create a branch.
2. Add your entry to the most relevant section, keeping the existing format:
   `- **[Name](https://link)** — One neutral sentence describing what it does.`
3. Keep descriptions accurate and vendor-neutral. Avoid marketing superlatives.
4. Open a pull request describing what you added and why it's useful for freelancers getting paid.

## Guidelines

- **Accuracy first.** Only claim what a tool actually does. No invented fees, partnerships, or endorsements.
- **Relevance.** Entries should genuinely help freelancers or contractors receive payments.
- **No duplicates.** Check the list before adding.
- **One entry per line**, alphabetical within a section where possible.

## Reporting issues

Found a broken link or an out-of-date detail? Open an issue — corrections are always welcome.
